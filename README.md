# JLPT N5 문법 — 조각으로 배우는 일본어

일본어 기초(N5) 문법을 **문장의 조각(화제 → 정보 → 질문)**으로 이해하는 웹 교재.
문장을 통째로 외우지 않고, `AはBです` 같은 뼈대에 단어를 갈아 끼우며 구조를 눈으로 익힙니다.

- 순수 HTML/CSS/JS · 외부 라이브러리 없음
- 모바일(출퇴근) 열람 우선 · 인터랙티브 시각화 포함
- GitHub Pages로 호스팅

## 강의

- **Lesson 1 · 일본어 문장의 첫 번째 뼈대 「AはBです」**
  화제 조사 `は`, `です`로 정중하게 끝맺기, `～ですか` 질문, `は→わ` 읽기, 문맥상 생략, 한·일 구조 비교, Sentence Anatomy, 7문항 퀴즈.
- **Lesson 2 · 아니다 · 이었다 · 아니었다 「명사문의 긍정/부정/과거 + も」**
  `ではありません`·`でした`·`ではありませんでした`, `じゃありません`, 조사 `も`(~도), `は vs も`. 4분면 그리드·2축 맵·Sentence Transformer·Grammar Growth·10초 복습, 8문항 퀴즈.
- **Lesson 3 · 누구의 것? 어떤 것? 「の · これそれあれ · このそのあの」**
  명사를 연결하는 `の`, 지시어 `これ/それ/あれ`·`この/その/あの`·`どれ/どの`, `これ vs この` 차이, `こそあど` 패턴. 명사 연결 블록·거리 시각화·슬롯 비교·Nested Sentence(탭하면 세분화), 8문항 퀴즈.
- **Lesson 4 · 행동에는 조사가 붙는다 「を / に / へ / で」**
  행동 문장의 핵심 조사 `を`(대상)·`に`(시간/도착점)·`へ`(방향)·`で`(장소/수단), 특히 `に vs で`. Sentence Blocks·Action Arrow·Time Pin·に vs で 공간 비교·같은 명사 다른 조사(인터랙션)·Chunk Reading·조사 역할 카드·Cheat Sheet, 9문항 퀴즈.
- **Lesson 5 · 어디에 무엇이 있을까? 「あります / います + に / が」**
  존재의 `あります`(사물)/`います`(사람·동물), 존재 장소의 `に`, 존재 대상의 `が`, `は vs が` 기초. あります vs います·Place→Entity→Existence·위치 표현(인터랙션)·질문→답 구조·존재 vs 행동·한 장소 세 역할·Nested Sentence, 9문항 퀴즈.
- **Lesson 6 · 합니다 · 하지 않습니다 · 했습니다 「ます / ません / ました / ませんでした」**
  동사 ます형의 현재/과거 × 긍정/부정. 4분면 동사 그리드·2축 맵·Sentence Transformer(동사 모드)·명사문 vs 동사문 대비·동사 어미 인터랙션·Everything Leads to the Verb, 9문항 퀴즈.
- **Lesson 7 · 일본어 동사의 정체 「사전형 + 1그룹 / 2그룹 / 불규칙」**
  사전형 개념과 동사 그룹 구분(`する`/`来る` 불규칙, `る`+い/え단 대체로 2그룹, 예외 `帰る` 등). 3그룹 개요·2그룹 る제거·1그룹 Ending Shift·그룹 판별 가이드·그룹 판별 인터랙션(탭)·Surface→Dictionary→Group, 9문항 퀴즈.

## 구조

```
index.html                 메인 허브 (강의 카드 자동 생성)
lessons/n5/0N.html         N5 강의 (asset 경로는 ../../assets/...)
assets/css/styles.css      디자인 시스템 + 강의별 컴포넌트
assets/js/main.js          공통 인터랙션 (사이드바·스크롤스파이·퀴즈·빌더·후리가나 등)
assets/data/lessons.js     강의 메타데이터 + 허브 렌더러
assets/fonts/              SCDream(본문) · omyu pretty(포인트) · 일본어는 시스템 폰트 스택
```

## 디자인 원칙

- 흰색/연한 중성 배경, **강조색 1개**(인디고) 중심, Warning은 절제된 앰버
- 조사(`は` 등)는 강조색 계열로 **통일**해 표시(무지개색 금지)
- 일본어 문장은 한국어 설명보다 시각적으로 조금 크게, Grammar Pattern이 가장 크게
- 한자는 본문에 후리가나를 항상 달지 않고, **탭/hover 시 툴팁**으로 읽기 표시

## 새 강의 추가 방법

1. `lessons/n5/0N.html` 추가 (Lesson 1 구조 복사)
   - asset 경로는 `../../assets/...`, 허브 링크는 `../../index.html`
2. `assets/data/lessons.js`의 `N5_LESSONS` 배열에 항목 한 줄 등록
   - `no`, `href`, `title`, `pattern`, `desc`, `tags`, `status: "ready"`
